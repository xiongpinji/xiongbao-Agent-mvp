## 仍开放的界面差距

1. **撤权后父页面缓存未同步清空。** 成员的项目动态 POST 返回 404 时，时间线和编辑框清空；同一画面中的项目详情右栏仍显示移除前读取的测试指令 `PS03_PRIVATE_INSTRUCTIONS_CANARY` 与过期「成员（2）」卡片，见 `attempt-2/browser/13-member-post404-cleared.png`。直接 PG/HTTP 已证实该身份新的读取被拒且成员表无此成员；当前证据说明旧授权数据仍在浏览器缓存，不说明服务端又向无权用户下发了数据。需要让父项目详情对孩子收到的撤权信号失效并清理相关缓存，再用同一四身份旅程复验。
2. **错误文案未本地化。** 控制浏览器加载更多的网络请求失败时，页面保留已加载数据和重试入口，功能恢复通过；浏览器记录读到 `Failed to fetch`，直接文字证据在 `browser-error-copy-timeout-1.json` 与 `browser-result.json`，`09-append-failure.png` 主要证明失败界面和重试入口。022 合同要求失败可重试，没有指定这次网络错误的精确中文文案；这仍是熊宝中文体验和 WorkBuddy UI 1:1 的开放差距。

独立只读复核把第一项定为 **P1 UI 隐私缓存缺口**，第二项定为 **P2 中文体验缺口**；第一项并非服务端撤权失败。消息中心、@ 提及、图片/富文本、精细通知、历史审计修订、WorkBuddy 同数据同视口逐状态视觉/键盘对照均未覆盖；不能因本批 PG/TCP 检查通过而勾选 PS-03。
