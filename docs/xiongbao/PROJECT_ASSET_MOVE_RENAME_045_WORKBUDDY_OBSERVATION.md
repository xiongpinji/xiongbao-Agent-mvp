# 045-F WorkBuddy 项目资产交互观察

2026-09-28 在用户已打开的 WorkBuddy 5.6.2 Windows 客户端中，只读观察项目详情的「资产」页。窗口为 1280 × 634；仅打开、关闭菜单和弹窗，未提交移动、重命名或删除。以下为实机观察，用作 045-F 视觉与交互验收参照；后端权限、分页和异常行为仍以已批准的 [045 设计](PROJECT_ASSET_MOVE_RENAME_045_DESIGN.md) 为准。

| 区域 | 观察到的行为 |
| --- | --- |
| 项目页 | 顶部为「动态 / 计划 / 任务 / 资产」标签；资产表格上方有「新建文件夹」「上传文件」、用量、类型筛选和搜索。表格列为名称、类型、更新人、更新时间、大小。右侧项目配置栏仍可见。 |
| 文件夹右键菜单 | 顺序为「添加到任务」「移动到」「重命名」，分隔线后为红色「删除」。菜单紧邻被操作的行。 |
| 文件右键菜单 | 顶部显示文件名，其后为「移动到」「重命名」「下载」「版本管理」，分隔线后为红色「删除」。 |
| 重命名 | 居中小弹窗，标题「重命名」，单行输入框，右下「取消 / 确认」。PDF 文件打开时，输入框预选主名，扩展名未包含在选区内；未改值时确认不可用。 |
| 移动 | 居中宽弹窗，标题「移动到项目资产」，右上关闭。上方为「项目资产」面包屑和搜索文件名，下方是名称、更新人、最近编辑三列表格；底部左侧「新建文件夹」，右侧「取消 / 确认」。目标文件夹可通过单选圆点选择，也可点名称进入，进入后面包屑显示「项目资产 > 文件夹」。文件在根目录时，目标列表只显示可选文件夹；文件夹在根目录时，自身不作为候选，普通文件行只作不可选展示。空文件夹显示居中空状态。 |

验收时需要核对菜单与文件预览的点击隔离、文件和文件夹均可打开两个操作弹窗、重命名的焦点与扩展名处理、移动窗口的层级导航和目标选中，以及窄窗下操作按钮可达。实机尚未验证根目录作为移动目标、101 个以上同层文件夹、冲突提示、撤权或项目切换后的异步结果；这些属于已批准规格和本地测试要覆盖的行为，不能从这次观察推断 WorkBuddy 的实现。
