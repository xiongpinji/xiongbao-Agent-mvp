# 项目计划表格中的一级子待办

本片承接已批准的 PS04D 一级子待办设计，给现有表格视图补上“显示子待办”能力。它复用已有关系和版本状态，不新增数据库迁移，也不启用待办附件、030 文件模式或 046 资产正文读取。

## 表格设置与兼容性

表格定义保持 `schema_version: 1`，增加严格布尔值 `show_subtodos`，默认 `false`。公共可见字段仍为原来的十种字段；内部附件字段合同继续保留在尚未启用的附件任务中。

旧表格定义缺少这个键时，普通读取、查询和逻辑视图响应将其解释为 `false`。新客户端保存或临时应用表格设置时显式发送所选布尔值。成员可以临时应用设置，共享视图保存仍要求项目 owner/admin。

旧客户端 PATCH 表格定义而省略此键时，服务端在核对当前视图、成员权限、`expected_version` 和目录版本的同一事务中保留已存值。显式发送 `true` 或 `false` 才改变它。过期版本仍冲突；其他视图转为表格且省略此键时使用 `false`。

列表、看板、甘特和日历定义不接受这个键，继续查询根待办。物理数据库备份保持原始数据库字节；恢复后的旧 JSON 通过普通读取获得默认关闭语义，不为这个布尔默认值重写数据库备份或补迁移。

## 查询与父待办入口

关闭开关时，表格仍只包含活跃根待办。开启时，服务端返回活跃根待办和一级子待办组成的平铺页面：每一行按照自己的字段参与筛选、分组、排序和分页。父待办不符合筛选时，符合筛选的子待办仍可出现；页面不保证父子相邻。

总数、分组计数、分页锚点及返回行使用一致的查询条件和授权读取快照。父标题通过受项目约束的有界查询投影取得，不逐行另开事务读取父待办。

只有计划查询响应新增 `parent_title: string | null`：根待办为 `null`，子待办为同一读取快照中的父标题。普通待办详情、旧列表和共享待办 DTO 保持原字段。子行缩进并提供父待办入口，即使父行不在当前页面，仍按父 ID 发起当前作用域下的详情读取。

本地写入后的普通待办快照可能不包含查询专属父标题，此时显示本地化的通用父待办入口，避免展示旧投影。账户、项目、视图和查询代次变化后，晚到响应与旧入口不能恢复已失效的页面状态。

根待办的完成数/子待办总数继续独立展示；开启开关不会在客户端重排父子行、重建服务端分组或修改这些统计。

## 游标

沿用 v2 游标，包含查询指纹、末行 ID 和显示版本。指纹绑定视图类型及有效开关值；开启子待办时还绑定项目层级版本。关系变化后的旧开启模式游标返回 `409 / query_changed`。关闭模式不会仅因层级版本变化而改变指纹，原有末行显示版本检查仍然有效。
