# 熊宝 Agent：Windows 安装包品牌显示首片

本片将 Windows 安装器名称、系统程序列表显示名称、Windows 文件属性和图标输入改为熊宝品牌。源码候选由四个文件组成；独立源码审查已通过。它属于 WorkBuddy 整体对齐中的 Windows 交付工作，不代表整体功能或 UI 已完成。

## 已实施的行为

- 安装器标题和产品属性显示 `熊宝 Agent`，系统程序列表的用户级、机器级两种注册分支均使用该显示名。
- Windows 文件属性的产品名称、文件说明和备注使用熊宝品牌。
- 安装包图标输入是现有熊宝 Logo 的原字节复制，未缩放、裁剪或重新编码。
- 新建熊宝快捷方式前检查目标是否存在；同名既存快捷方式保持原状。此片卸载时保留快捷方式，后续具备可靠目标归属检查后再处理残留。
- 卸载只删除已知执行文件和卸载器，最后尝试非递归删除空安装目录。安装目录中的其它文件和 AppData 保留。

为保持升级识别，本片继续使用 `Octop.exe`、既有 Octop 安装目录、`OctopOctop` 卸载登记键及原制品文件名。公开制品改名属于后续同步迁移。
