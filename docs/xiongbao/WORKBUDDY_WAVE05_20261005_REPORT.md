# 熊宝-Agent：会话归档与数据管理候选（2026-10-05）

本批为 WorkBuddy 对齐计划中的会话归档交付片段。功能分支为
`feature/workbuddy-full-parity-20261004`，继续通过既有草稿 PR #2 整合到
`develop`。本报告当前记录固定候选，整体 WorkBuddy 功能、UI 和 Windows
交付仍在进行。

## 用户行为

- 会话菜单支持归档；恢复可从当前会话提示或数据管理页操作。普通列表和标题搜索隐藏本人已归档会话。
- 当前已打开的会话保留阅读、草稿和执行上下文，归档不停止任务，也不删除历史。
- 设置中的数据管理页集中列出本人已归档会话，支持标题搜索、分页、失败重试及恢复。
  普通用户可以进入该页，停止运行的智能体所对应的合资格记录也可列出。
- 项目任务的拥有者可以归档自己的会话；共享阅读者保留既有阅读范围，不能读取他人的
  私人归档状态，也不能操作他人的归档。
- 归档请求按当前用户、智能体和会话隔离。账号切换、页面重挂和搜索变化期间，真实请求
  完成前继续阻止重复写入；请求结束后按钮重新可用。键盘打开极简菜单保持当前导航。

## 实现与兼容

后端新增 038 SQLite/PostgreSQL 配对迁移、归档服务和受控查询/修改接口；在同一数据库
事务中检查当前用户与智能体访问资格。已应用的归档结构异常会拒绝启动迁移，不自动重建。
仅有用户表的受支持旧 SQLite 库继续升级；存在智能体表但缺少历史表时仍拒绝归档迁移。

备份保留归档状态和原会话绑定。恢复测试比较全部 SQL 语句及重复数据，同时保留原有
回滚、私有文件、恢复前镜像和资源清理断言；不以 schema 对象创建顺序作为数据变化。

本批还修正待办标签在主题中的背景和文字 token，并纠正上一批 CI 报告的 SHA 范围：
上一批 CI 检查的是 PR 合并提交，不能代表本批尚未发布的源码。
