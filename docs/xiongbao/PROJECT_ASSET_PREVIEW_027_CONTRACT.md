# 027 项目资产 PDF 版本预览与私有路径日志修复

## 目标和取舍

WorkBuddy 5.6.2 的项目资产“版本管理”右栏会预览选中版；熊宝 026 右栏目前只有占位。本批让项目成员在同一弹窗预览 PDF 历史版本，并清除孤儿回收器的一条私有路径日志风险。此批不核销项目资产完整能力或 WorkBuddy 1:1。

考虑过三个方案：外部文档预览服务最接近所见界面，但会把私有字节交给第三方；无类型限制地复用所有 Office 解析器覆盖更广，但新版本上传没有校验扩展名与真实内容一致；限定 PDF、通过现有授权下载接口在本地 PDF.js 渲染，范围最小且可验证。因此本批选第三种，Office/图片/文本、文件删除/回收/配额和任务引用留给后继批次。

## 行为与边界

- 仅文件名后缀 `.pdf`（大小写不敏感）、该**选中版本** `media_type=application/pdf`、`0 < size_bytes <= 25 MiB` 时自动尝试预览；其他类型或超限明确显示“此类型暂不可预览，可下载查看”，不发起预览下载。列表版次只是显示值，获取字节必须使用当前 `version_id`。
- 复用 `GET /api/projects/{project_id}/assets/{node_id}/versions/{version_id}/download` 的登录态 `requestBlob`。这个已有端点每次检查当前成员资格、节点和版本归属；绝不公开持久 URL、对象键或本地路径，不调用腾讯文档或其他外部预览服务，也不新增后端预览端点。
- 子组件按需载入 `DocumentPreviewCore`；模块加载失败显示本地可重试错误，不牵连版本列表和独立下载按钮。在传给核心组件的 `fetchBlob` 回调中使用登录态 API 取字节，先拦截 404 再将经过校验的 Blob 返回；绝不把端点 URL 交给核心组件或让其通用错误处理吞掉撤权 404。收到字节后在本地验证前五个字节为 `%PDF-`；不符时显示可重试的解析失败态，不把其内容当 HTML、SVG 或脚本渲染。实际 Blob 超过 25 MiB 也拒绝渲染。PDF.js 负责加载、缩放和滚动；仍保留原有独立“下载该版本”按钮与认证流程。预览区高度受弹窗与窄屏约束，不盖住版本操作。
- 首次选择/切换版本、关闭弹窗、项目或节点切换、撤权时终止旧预览请求；每次 `await` 后、调用弹窗回调或交回 Blob 前都重新检查 AbortSignal 和项目/节点/版次作用域，晚到的旧版本结果不得显示或触发新项目错误。预览下载返回 404 时按 026 已有规则清空弹窗并由父页重新检查项目权限；若仅历史对象缺失而成员仍在，弹窗保持关闭、不自动反复打开。其他网络/解析错误只影响预览，提供重试和独立下载。必须处理 AbortError，不产生错误提示。
- 将 `projectAssetsApi.downloadVersion` 的可选 `RequestInit` 和进度回调透传给既有 `requestBlob`，保持三参数旧调用兼容。取消信号既用于预览，也可用于原下载按钮以关闭/切换时节省流量。服务端 ACL 才是最终权限边界。
- `ProjectAssetStorage.reclaim_orphans` 的逐条目 `OSError` 警告只写固定消息，不附带异常或路径；保留跳过该条目、继续处理其他条目的行为。以注入包含绝对私有路径的异常写先失败后成功测试。026 文档同时明确 Windows API 集成 25 为日志修复后，WSL API 集成 25 为修复前的结果。

## 分工和验收

Codex 固定合同并整合。Claude/Qwen3.8 Max 只拥有后端回收器、后端单测、项目资产 API 客户端及其单测；OpenCode/DeepSeek V4.1 Flash 只拥有版本弹窗及其测试。两人分别在独立 worktree 工作，不提交、推送、改凭据、清理数据或创建子代理。Codex 独占本合同、中文/英文 locale、差距/验收文档和最终提交。

先写失败测试。至少覆盖 PDF 首次预览/切版、签名不符、超限与非 PDF 不请求、预览 404、普通失败重试、关闭/切项目取消与晚到响应、API `signal` 透传、回收日志路径不外泄。Codex 独立跑受影响 Python/前端测试、格式/类型/构建，做成员/撤权浏览器旅程与 1280×768、760×720 截图对照。GLM 只读检查固定代码 SHA 的权限、取消、资源释放和错误态；P0/P1 修复后才推送并校验远端 SHA。真实 PG、安装包和全部 WorkBuddy 页面仍保留为未验。
