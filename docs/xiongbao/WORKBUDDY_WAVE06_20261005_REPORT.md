# 熊宝-Agent：项目公共连接器存储与桌面品牌候选（2026-10-05）

本批继续使用 `feature/workbuddy-full-parity-20261004` 和草稿 PR #2。当前为固定源码候选，
整体 WorkBuddy 功能、交互、UI 和 Windows 交付仍在推进。本报告不构成完整产品验收。

## 项目公共连接器存储

新增项目专属的静态 Bearer HTTP MCP 配置存储、领域服务和 039 SQLite/PostgreSQL
配对迁移。安全读取仅返回名称、描述、状态、版本和时间等八个元数据字段；地址、
令牌和密钥不进入安全 DTO。凭据加密绑定项目、资源和授权版本，使用独立密钥。

项目 owner/admin 可创建、修改和撤销，member 可读取安全元数据；撤权、禁用用户和
项目资格在同一事务中检查。写入使用项目版本与授权版本检查，拒绝过期修改。
归档项目保留读取和撤销，拒绝新增、换凭据与改名。撤销清空凭据并保持终态；
迁移发现已应用结构异常时拒绝启动，不自动重建。

本片尚未添加 HTTP 接口、配置界面或任务中的工具调用。接口及界面合同已固定，
后端任务包已通过 Agent Orchestrator 格式校验，等待存储验证完成后实施。

## 桌面品牌

桌面壳的可见名称、提示和加载页使用熊宝 Agent，加载页及适用平台的应用/托盘图标
复用已批准的熊宝 Logo。内部应用标识继续保留 `Octop`，避免改变旧 macOS 后台服务
身份；现有数据目录、配置位置和命令保持兼容。

本地已构建 Windows x64 可执行候选，但未启动该候选或制作、安装发布包。
macOS 打包图标、安装交付和最终窗口显示效果仍待验收。
