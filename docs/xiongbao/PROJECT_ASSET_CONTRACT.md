# 熊宝-Agent 项目资产合同（PS-06A / 023 草案）

状态：2026-09-24，待独立只读设计审查，尚未实施。018–022 的项目域和成员权限是依赖；023 仅在 022 已合入后分配。WorkBuddy 5.5.6 本机只读观察到了资产页的文件夹、上传、筛选、搜索、容量、列表和“添加到任务”入口，官方更新日志提到版本历史；没有在 WorkBuddy 实测上传、下载、版本或内部授权。以下数据与权限是熊宝自己的产品合同，不推断 WorkBuddy 的实现。

## 交付边界

本批先交付 **023A 项目资产基础**：独立私有存储根、文件夹、文件上传、列表、名称搜索、类型筛选、容量展示和登录成员下载。每次上传创建不可变版本记录，为 023B 的版本历史/恢复留好数据模型。023B 再开放版本列表、同名文件新版本、删除/恢复与空间回收。任务引用要等 PS-05B 任务协作者 ACL 定稿后单独接入；023A 页面应将“添加到任务”明确禁用并说明原因。项目资产绝不落入 Agent 工作区、个人资料库、公开静态目录或浏览器可猜测 URL。

023A 不做图片预览、全文索引、外部对象存储、分片续传、批量上传、文件夹移动或客户端本地路径引用。没有实际后端的控件不能显示为可用。文件版本/删除尚未开放时，页面不能暗示已支持。资产列表和下载不因项目成员身份扩展到任何任务私聊、Agent 文件或个人 OAuth 凭据。

## 身份、名称与结构

- 仅当前 `project_members` 中的 owner/admin/member 能列出、搜索、下载、创建文件夹和上传。非成员、已撤权成员、未知项目/节点统一 404；已登录成员对未来受限管理动作可用 403。每个列表、下载、版本、旧版本和未来任务引用请求均重复服务端授权；资产 ID、版本 ID 和对象键均不是授权凭证。
- 一个项目有一个隐藏根文件夹节点。所有可见节点都以 `parent_node_id` 指向同项目文件夹；不能跨项目挂接，不能把文件当父节点。项目创建后的老项目在首次资产操作时幂等初始化根。根节点不能被重命名、移动或删除。
- 同一父文件夹内，名称经过 Unicode NFC 与首尾空白处理后，1–120 个字符且唯一；拒绝 `/`、`\\`、NUL、控制字符、`.`、`..` 与 Windows 保留设备名。文件名只作为显示元数据，最终对象路径由服务端生成，不拼接用户文件名。不同父文件夹允许同名。
- `project_asset_nodes` 持有 `node_id`、`project_id`、`parent_node_id`、`kind`、`name`、`name_key`、`created_by`、`created_at`、`updated_at`；`project_asset_versions` 持有 `version_id`、`project_id`、`node_id`、`object_key`、`size_bytes`、`sha256`、`media_type`、`uploaded_by`、`created_at`。两表须由 023 配对 SQLite/PostgreSQL 迁移建立，项目删除级联仅清理元数据，物理对象由受控回收流程处理；作者删除后元数据可显示已删除用户。父节点和版本都用包含 `project_id` 的复合外键防止跨项目误挂接；版本不可原地覆写。
- 023A 文件节点只有一个当前版本，不暴露“上传新版本”；目录创建和文件上传都由服务端生成不可猜测 ID。按 `(project_id,parent_node_id,name_key)` 在数据库层防同名并发。根的唯一性在两库均由约束保证，不能只靠应用先查后插。后续版本/软删除迁移不得改写旧版本的对象字节。

## 上传、存储与容量

- 使用 `PathLayout` 下独立的服务端私有项目资产根；对象键仅由服务端版本 ID 导出。临时文件与最终对象位于同一文件系统，以便校验后原子发布。拒绝符号链接、路径逃逸、空文件名和超出配置上限的文件；流式读取并在上限处停止，不能将整文件无界读入内存。前端可显示上传进度或明确等待态，失败可重试且不得显示半成品。
- 上传先流式写到私有临时对象并计算 SHA-256/实际字节数，再在持有项目成员与父节点授权的数据库事务中预留名称和元数据；物理对象与数据库无法组成单一事务，所以实现须定义崩溃恢复：只有最终对象存在且元数据提交后才对列表可见，异常清理临时文件，孤儿最终对象由可审计的受限清理器回收。不要在请求失败后递归删除任意路径。
- 023A 的“容量”只显示已提交且当前可访问文件版本的 `size_bytes` 汇总及文件数，不显示虚构配额。全局 `max_upload_mb` 是单文件上限；项目配额和历史版本计费在 023B 定规则后实施。文件 MIME 由服务端安全探测或保守使用 `application/octet-stream`，浏览器声明的类型仅作提示；下载响应固定 `Content-Disposition: attachment`，阻止用户上传的 HTML 被同源内联执行。
- 下载先在同一请求重新检查项目成员资格、节点归属、版本归属及对象真实路径，再从私有根流式返回；不生成静态对象 URL、公开绝对路径或长期签名链接。下载/列表 JSON 不返回 `object_key`、服务端绝对路径、临时路径或存储凭据。撤权后旧深链再次请求必须 404。
- 上传/下载不会触发模型或第三方服务，不把内容放进项目动态事件、日志或异常正文。可记录安全审计摘要：操作者、项目、节点/版本 ID、时间、结果和字节数，不记录文件正文、原始 multipart 或本机绝对路径。

## HTTP 与界面合同

| 路由 | 行为 | 关键失败 |
| --- | --- | --- |
| `GET /api/projects/{project_id}/assets?parent_id=&q=&kind=&limit=&offset=` | 当前文件夹直接子节点；服务端按名称搜索/类型筛选并稳定分页，返回节点安全元数据和 `total/has_more`。无 `parent_id` 表示隐藏根 | 非成员/不存在父节点 404；非法参数 422 |
| `POST /api/projects/{project_id}/assets/folders` | `{parent_id?,name}` 创建文件夹，201；缺省父节点为隐藏根 | 非文件夹父节点 422；同名 409；非成员 404 |
| `POST /api/projects/{project_id}/assets/upload` | multipart `file` 和可选 `parent_id`；存储成功才返回节点与首版安全摘要，201 | 超限 413；同名 409；非成员 404；失败不得留下可见记录 |
| `GET /api/projects/{project_id}/assets/usage` | 已发布文件数和当前版本字节数 | 非成员 404 |
| `GET /api/projects/{project_id}/assets/{node_id}/download` | 当前版本的私有流式附件 | 非成员、跨项目、撤权、文件缺失统一 404；绝不回退到其他项目同名文件 |

Dashboard 资产页接真实接口，呈现面包屑、文件夹/文件列表、上传、名称搜索、类型筛选、容量、加载/空/失败态；切换项目或目录后不闪现旧资产，晚到请求不可覆盖新项目。owner/member 的真实浏览器上传、下载与刷新必须一致；非成员不能从 API 或旧链接访问。文件名作为纯文本渲染。未完成的版本、删除和添加到任务功能应标明后续批次。

## TDD 与验收门槛

先写失败的迁移/仓库/API/前端行为测试，再实现。至少覆盖 SQLite 新库及 022→023 升级、根初始化幂等、同父同名竞争、跨项目父节点和节点/版本 ID、非成员与撤权后下载 404、文件名路径字符、空/超限上传、上传中断和数据库失败不产生可见文件、目录与类型筛选先于分页、相同排序键稳定分页、下载字节与 SHA 一致、响应不暴露物理路径。模拟故障不能替代实际浏览器下载；跨数据库静态 SQL 对照不能替代 PostgreSQL 真实迁移和并发实测。

Codex 独立检查差异与路径白名单，运行受影响后端/前端回归、类型/格式/生产构建，做 1280×768 三身份隔离浏览器旅程，并由 GLM 只读复核资产路径与 ACL 后才推送。023A 完成也不代表 PS-06 或 WorkBuddy 1:1：023B 版本历史/恢复/删除、项目配额与真实存储回收，后续任务引用和视觉逐状态仍单独验收。
