# PS-04C 截止日期日历月份导航补验（2026-09-30）

范围仅为项目待办日期弹窗的月份导航和键盘关闭。既有 [WorkBuddy 5.6.2 实机观察](PROJECT_TODO_PS04C_WORKBUDDY_OBSERVATION.md)记录：截止日期日历在当天所在月禁用「上个月」，当天以前的日期也不可选。熊宝先前仅在越过 1900 年边界时禁用该按钮。

修复 `c65ff4b5ae04e142f75bdfc269dc6d39eeb4aa92` 使新截止日期不能点「上个月」进入整个月均已过期的月份；开始日期仍能浏览过去月份。编辑旧待办时，原有已逾期截止日期所在月仍可从下一月返回，且仅原日期可保留。返回最早可浏览月份后，如果「上个月」随即禁用，焦点转移至仍可用的「下个月」，Escape 仍可关闭弹窗并将焦点还给日期入口。
