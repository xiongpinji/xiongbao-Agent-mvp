# 熊宝-Agent × WorkBuddy 5.5.6 对标与实施路线

更新：2026-09-25。目标是让熊宝-Agent在**功能结果与桌面交互上逐项达到 WorkBuddy 对标水平**，并使用用户提供的熊宝品牌素材。此文档是验收台账：源码存在、官方文档描述、页面可见和真实任务走通是不同级别的证据；未完成的项目不得视为 1:1 已实现。项目资产版本窗格另有 WorkBuddy 5.6.2 实机观察。

## 比对基准

- 源码：腾讯开源 [TencentCloud/Octop](https://github.com/TencentCloud/Octop)，本地基线 `c7f828676e14c30910409ea2e35d54f8efd930e7`（`origin/develop`），MIT 许可证。Octop 官方 README 声明 Web/IM/CLI、专家、连接器、RAG、cron、浏览器、远程桌面和 ACP 等能力；这些声明不等于熊宝-Agent 中已完成用户验收。
- 产品：用户已启动的 WorkBuddy 5.5.6 任务首页窗口，以及腾讯云 [入门指南](https://cloud.tencent.com/document/product/1831/134389)、[新建任务栏](https://cloud.tencent.com/document/product/1831/134391)、[右侧边栏](https://cloud.tencent.com/document/product/1831/134400)、[自动化说明](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Automation-Guide)、[专家市场](https://open.workbuddy.cn/docs/expert)、[连接器](https://open.workbuddy.cn/docs/connector)。WorkBuddy 窗口观察到左侧新建任务/助理/项目/专家·技能·连接器/定时任务/资料库等入口、任务历史；中央日常办公/代码开发/设计创意切换、建议任务、编辑区、工作空间/访问范围；右侧概览/产物。
- 熊宝视觉：用户提供方形红黑熊宝 Logo、角色造型板和深色金色工作台效果图。效果图的示例对话、文件名与命令是视觉样例，不是实现指令。复制的是用户期望的信息架构和交互效果；产品标识、素材与文案使用熊宝自己的版本。

状态说明：**基线有**＝代码或上游文档可定位，仍待熊宝实测；**代码及定向测试通过**＝第一阶段实现已完成并通过对应单测，但不代表 WorkBuddy 真实桌面验收；**部分实现·待桌面验收**＝可运行基础已建立，完整行为或视觉尚未证明；**差距**＝当前未证明达到 WorkBuddy 行为；**待验收**＝需要真实端到端或视觉回归证据。

## 阶段次序与停门

1. **首批基础工作台（源码已实现）**：两条隔离实施线分别处理品牌/主题/场景欢迎页，以及右侧概览/产物。Codex 独立整合与验收，GLM-5.3 只读审查指出的可点击品牌入口已修复。交付标“首版基础”；真实任务桌面与 WorkBuddy 1:1 验收仍待后续阶段。
2. **项目空间 P0**：按 [专项执行计划](PROJECT_SPACE_EXECUTION_PLAN.md) 先做项目与 ACL 基座，再完成成员、计划、任务共享、资产、动态和配置；本地目录安全边界独立推进。逐项用多用户桌面旅程验收。
3. **任务与结果闭环**：任务目录、历史管理、完整四区结果、真实文件 diff、运行预览。每项以可复现的桌面用户旅程验收。
4. **专家与办公生产力**：专家市场、技能/连接器、资料库、自动化，以及真实 Word/PPT/Excel/PDF 任务。优先复用 Octop 已有能力，缺的才扩展 API。
5. **跨端/桌面交付**：专家团编排、跨端、安装更新、视觉与可访问性回归。每次只在完成代码、测试、审查和用户旅程后更新矩阵状态。

源码基于本地功能分支推进，并按用户授权推送其 GitHub 仓库。部署、付费生产模型调用和第三方授权不属于本次本地首批实现。
