## 留待设计与验收的边界

- 指令与专家的当前快照规则可作为研究起点；技能/连接器/定时规则各自需要项目角色写入、任务创建和运行时再授权、版本/撤权语义。共享项目成员身份本身不能给其他人个人连接器凭证、Agent 或本地工作目录的权限。
- 个人授权连接器和公共团队凭证是两个不同的资源及审计域；后者的持有者、项目成员使用范围、撤销与秘密轮换需要单独定合同。WorkBuddy 弹窗文字并未证明这些后台机制。
- 项目技能至少要区分技能中心选择、上传文件、Agent 实际加载和运行时权限；项目定时任务至少要区分规则归属、调度执行身份、私密任务产物与运行记录。这些均不可直接沿用用户/Agent 级数据表并声称项目功能已实现。
- 后续每一片需分别做 SQLite/PostgreSQL 迁移与权限测试、多身份 HTTP、真实浏览器入口，以及模型/调度运行和撤权后的失效验收；本次没有执行这些测试。
