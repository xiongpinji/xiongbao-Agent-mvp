# 028 · 项目内创建私密任务与指令快照验收

状态：实现与本地定向验收已完成；固定提交的 GLM 只读审查、最终 SHA 推送核对及下列未实测项分别记录。本批是 [028 合同](PROJECT_TASK_CREATE_CONTEXT_028_CONTRACT.md) 的 PS-05C/PS-07A 第一片，不核销整条项目空间旅程。

## 已实现的行为

- 项目成员在“任务”页预览当前项目指令全文，选择自己可用的单专家并主动确认；服务端用预览摘要复核当前指令，同一写事务创建私密 Dashboard 对话、历史投影、`source=project` 关联与不可变快照。创建成功进入创建者对话，**不自动发送首轮消息**。专家团会委派到其他专家，故本批禁止其创建项目任务。
- 旧摘要返回 409 且不留下任务。前端清除确认、刷新项目详情；关闭重开弹窗或刷新时摘要短暂缺失都不能重交已拒绝摘要。拿到新摘要后需再次确认。失败不插入虚假任务卡片。
- 每轮网关以 thread owner、agent、有效项目成员关系、未归档项目及 `source=project` 关联，从服务端快照取指令，追加在专家原 system message 后。客户端伪造项目元数据不被用作快照。解绑、退组、项目归档后，下一轮不再注入。手动关联旧任务没有快照。
- 任务卡片仍默认只对创建者可见；项目成员身份不解锁其他人的对话、附件、工作目录或个人 OAuth。项目右栏明确说明指令编辑只影响新任务，专家/技能/连接器/定时规则仍显示未开放。
