## 用户可见行为

- 项目成员可在详情右栏读取管理员保存的有序专家名单；owner/admin 可打开“管理专家”，搜索、添加、移除、排序、取消或保存。列表仅接受当前全局共享、启用、运行中的单专家。成员只有只读展示，外人无法通过接口读取。
- 已取消共享、停用或删除的专家以不可用占位显示，不返回当前名称或描述。管理员保存采用修订号；陈旧保存返回 409，真实无变化保存不增加修订号。安全的“更新项目专家”事件出现在动态中，不附带私有 Agent 配置。
- 名单非空时，新建项目私密任务只能选择名单内且操作者本人仍有权限使用的单专家，提交时携带预览到的名单修订号；服务端同事务复核项目成员、项目与 Agent 当前状态，不把项目名单当作 Agent 授权。名单为空时保持 028 的旧行为。成功只进入新对话，不自动发送消息；既有任务和指令快照不因名单修改而变化。
- 项目右栏的连接器、技能、定时任务继续标为“暂未开放”；名单不授予个人 OAuth、工作目录或其他成员的任务正文权限。
