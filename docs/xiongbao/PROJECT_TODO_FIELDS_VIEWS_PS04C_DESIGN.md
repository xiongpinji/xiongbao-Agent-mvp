## 主要产品选择

1. **计划日期为日历日。** 使用严格 `YYYY-MM-DD`，不把它转成 UTC 时刻。服务器配置时区决定“今天”。新建或改变截止日期时不得早于服务器今天；已经逾期的旧值可以原样保留。开始日期可以在过去；两项存在时开始不得晚于截止。清除与 409 保留草稿规则见 C1。
2. **目录是项目配置。** owner/admin 管理优先级和标签；所有当前成员可读取、选择有效项，待办写权限仍受创建者/当前处理人规则限制。成员不能因操作标签而取得改他人待办或配置的权限。目录项停用保留旧引用，不隐式改写待办版本；恢复或新增关联必须经过修订与同项目校验。
3. **视图为项目共享配置。** owner/admin 创建、编辑、停用/恢复和设置项目默认视图；成员可读取并临时调整当前会话的字段/筛选/排序，不能覆盖共享配置。临时调整与“保存到共享视图”明确区分。上次选择的有效视图可按当前账号和项目保存 ID，不保存标题、待办或私密配置内容。
4. **五种视图使用完整查询语义。** 分组数和结果总数由服务端对过滤后的全项目数据计算；分页不把已加载 50 条冒充全项目。甘特与日历必须渲染真实计划日期，拖动和键盘日期编辑均调用版本化 PATCH。
5. **未知能力保留完整差距。** 待办附件不同于评论图片，子待办不同于平面待办，数据源导入不同于手工“来源”标记。下面的后继队列明确保留它们，不以可点击空壳或全零附件列提供完成证据。

这些角色、日期与共享规则是本次需要批准的产品决定；实机只读菜单没有证明它们与 WorkBuddy 保存后的行为一致。
