## 项目公共连接器配置

新增项目公共连接器的列表、创建、改名、换凭据及撤销接口，以及项目详情配置卡片。
owner/admin 可管理；member 只读安全元数据。接口返回名称、描述、状态、版本及时间，
不返回地址、令牌和密钥。凭据只存在于本次输入过程，取消、完成、失败、切换项目或
切换账号后清除；界面不回显原始服务错误中的输入内容。

写入使用项目版本和授权版本检查。权限变化、归档、撤销、过期修改和迟到响应不会
自动重放写入。撤权会清除配置集合及编辑弹窗；保存过程中仍可取消。归档项目保留
安全读取与撤销，禁止新增、改名和换凭据。已撤销配置保持终态。

HTTP 输入限制大小并校验严格字段，错误响应不包含提交的凭据。路由将同步领域调用
交给执行器，继续由领域事务检查权限和完成存储。本片完成配置管理，不包含项目
公共 MCP 工具执行、技能、定时任务或 OAuth 运行时验收。

## 项目加入审批

审批在同一事务中重新检查处理人、申请人、项目、请求和成员资格，并采用固定锁顺序。
成员被移除、降权或禁用，以及申请人被删除时，审批依据事务中的当前状态处理；
同时批准与拒绝只能产生一次有效结果。请求状态、成员写入与安全事件必须一起提交。

SQLite 特殊中断在连接锁释放前回滚；回滚失败时关闭同一连接并保留原始异常。
普通异常及 PostgreSQL 继续由现有事务适配器处理。事务故障不会被转换为成功响应。
