# 第二波：会话元数据与个人 MCP 调用上下文

本批解决两个具体问题：会话改名/置顶的失败或晚到响应可能覆盖新状态；共享智能体曾将个人 MCP 工具加入全局工具集合。实现只核销这些有界行为，完整 WorkBuddy 对齐仍在进行。

## 实现范围

- 会话元数据：主列表、极简当前会话、其他专家预览和非对话页记录侧栏共用明确的保存结果。按专家/会话/字段限制单次保存，不合并整份陈旧响应；失败只回滚对应字段。保留既有分页、自动初始标题以及内部任务的手动修改限制。
- 个人 MCP：由服务端解析的当前用户、专家、会话和来源构造调用上下文；模型阶段展示当前个人描述与参数结构，工具阶段重新核对当前配置和描述指纹。个人工具不加入共享智能体全局集合。当前采用动态 eager 描述；显式 deferred 名称冲突会拒绝该个人工具路径。
- 暂停确认：过程内 pending 记录保存模型实际使用的个人工具 receipt；恢复时核对原身份、一次性领取及锁内过期检查，嵌套暂停保存新模型阶段 receipt。网页、IM 和定时任务入口均接线。该记录不发送给客户端，也没有重启恢复承诺。
- 折叠导航：为图标按钮提供本地化可访问名称和当前页语义。
